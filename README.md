2) Тема проекта: автоматизированная система контроля параметров аквариума с мобильным управлением.

3) Задачи:
  - Разработка модуля сбора данных с датчиков температуры, pH, уровня воды и освещённости на Raspberry Pi.
  - Реализация автокормления по расписанию и порциям, управление освещением, фильтром и помпой.
  - Построение backend на Linux-сервере: REST API и MQTT, хранение телеметрии, push-уведомления при выходе параметров за пороговые значения.
  - Создание Android-приложения с дашбордом, графиками, ручным управлением и настройкой сценариев.

4) Ожидаемый результат к декабрю 2026 года: работающий прототип умного аквариума с мониторингом 4–5 параметров, автокормлением, Android-приложение, задокументированный API, отчёт о тестировании.
